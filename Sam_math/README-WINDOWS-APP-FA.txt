SAM MATH — آماده‌سازی برنامهٔ ویندوزی

مهم: این بسته هنوز فایل EXE ساخته‌شده ندارد؛ این فایل‌ها ابزار ساخت برنامه را اضافه می‌کنند. برای ساخت EXE باید مراحل زیر روی یک کامپیوتر ویندوزی با اینترنت انجام شود. روی کامپیوتر مدرسه برای اجرای EXE نیازی به Node.js یا VS Code نیست.

۱) کل پوشهٔ SAM-MATH را از ZIP استخراج کن، مثلاً در D:\SAM-MATH.
۲) روی کامپیوتر خودت Node.js نسخهٔ LTS را از وب‌سایت رسمی نصب کن: https://nodejs.org/
۳) پوشهٔ SAM-MATH را در File Explorer باز کن، روی نوار آدرس کلیک کن، cmd بنویس و Enter بزن.
۴) در پنجرهٔ ترمینال این دستورها را جداگانه اجرا کن:
   npm install
   npm run start
۵) اگر برنامه درست باز شد، نسخهٔ قابل‌حمل را بساز:
   npm run build:portable
۶) فایل EXE در پوشهٔ release ساخته می‌شود. آن را روی ویندوز دیگری هم آزمایش کن. ممکن است SmartScreen هشدار بدهد چون برنامه امضای دیجیتال ندارد.

برای ساخت نصب‌کنندهٔ ویندوزی نیز می‌توانی اجرا کنی:
   npm run build:installer

نکات:
- فایل‌های اصلی سایت حفظ شده‌اند و فایل‌های کش حساب Wrangler از بسته حذف شده‌اند؛ آن کش برای اجرای سایت لازم نیست.
- ابزارهای ریاضی محلی می‌توانند بدون اینترنت کار کنند. SAM AI به اینترنت و فعال بودن Worker در Cloudflare نیاز دارد.
- تاریخچهٔ SAM AI که در localStorage ذخیره می‌شود معمولاً به همان دستگاه/پروفایل محدود است و خودکار بین دستگاه‌ها همگام نمی‌شود.
